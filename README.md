## 🌟 Overview / परिचय

**Courtkey** is a professional desktop typing application tailored to match the exact examination guidelines of the **Madhya Pradesh High Court** and **CPCT (Computer Proficiency Certification Test)**. It features the standard **Remington Gail Keyboard Layout** and a strict 50-marks evaluation engine complete with backspace and penalty tracking.

कॉर्टकी (Courtkey) एक प्रोफेशनल डेस्कटॉप टाइपिंग सॉफ़्टवेयर है जिसे विशेष रूप से **मध्य प्रदेश उच्च न्यायालय (MP High Court)** और **सीपीसीटी (CPCT)** परीक्षा के पैटर्न को ध्यान में रखकर बनाया गया है। इसमें मानक **Remington Gail कीबोर्ड लेआउट** और सटीक मार्किंग सिस्टम दिया गया है।

## 🚀 Key Features / सॉफ़्टवेयर फ़ीचर्स

### 1. Select Paragraph / पैराग्राफ चयन
* **English:** Choose different paragraphs or files for typing practice.
* **हिंदी:** अभ्यास के लिए अलग-अलग पैराग्राफ या फाइल चुनने की सुविधा।

### 2. Keyboard Layout / कीबोर्ड लेआउट
* **English:** Supports Remington Gail Layout for Hindi typing.
* **हिंदी:** हिंदी टाइपिंग के लिए Remington Gail Layout का समर्थन।

### 3. Live Performance Tracking / लाइव परफॉरमेंस ट्रैकिंग
* **English:** Real-time tracking of Time, Gross Words Per Minute (GWPM), Net Words Per Minute (NWPM), Accuracy, and total words.
* **हिंदी:** टाइपिंग के दौरान समय (Time), ग्रॉस वर्ड्स पर मिनट (GWPM), नेट वर्ड्स पर मिनट (NWPM), एक्यूरेसी (Accuracy), और कुल शब्दों की गणना।

### 4. Backspaces & Penalties Monitor / बैकस्पेस और पेनल्टी मॉनिटर
* **English:** Displays backspace count, total marks, and penalty deductions.
* **हिंदी:** बैकस्पेस काउंट, कुल मार्क्स और पेनल्टी अंक देखने की सुविधा।

### 5. Special Characters / स्पेशल कैरेक्टर्स
* **English:** Special character help option to view and type complex Hindi letters.
* **हिंदी:** विशेष और जटिल हिंदी अक्षरों को टाइप करने के लिए स्पेशल कैरेक्टर शॉर्टकट विकल्प।

### 6. Customizable Settings Panel / कस्टमाइज़ेबल सेटिंग्स पैनल
* **English:** Configure Total Paragraph Marks, Wrong Word Penalty, Backspace Penalty, Total Words Limit, Live Highlighting & Colors, Minimum Minutes to Stop Test, and Required Speed (NWPM).
* **हिंदी:** पैराग्राफ के कुल अंक, गलत शब्द पेनल्टी, बैकस्पेस पेनल्टी, शब्द सीमा, लाइव हाइलाइटिंग, और आवश्यक स्पीड सेट करने की सेटिंग्स।

### 7. Add Custom Text / कस्टम टेक्स्ट जोड़ें
* **English:** Option to input custom paragraphs or text for practice.
* **हिंदी:** अभ्यास के लिए खुद का पैराग्राफ या टेक्स्ट जोड़ने की सुविधा।

### 8. Exam Marking System / परीक्षा मार्किंग सिस्टम
* **English:** Built-in grading system based on MP High Court and CPCT examination guidelines (50 Marks system).
* **हिंदी:** मध्य प्रदेश उच्च न्यायालय और सीपीसीटी (CPCT) परीक्षा के पैटर्न पर आधारित मार्किंग सिस्टम।

### 9. Timer & Session Controls / टाइमर और सेशन कंट्रोल्स
* **English:** Configure test duration (e.g., 10 minutes) and use Show, Stop, and Restart controls.
* **हिंदी:** टेस्ट के लिए मिनट चुनने का विकल्प और शो, स्टॉप व रीस्टार्ट बटन।

### 10. License & Activation / लाइसेंस और एक्टिवेशन
* **English:** View license status and activation validity using the **F1** key.
* **हिंदी:** सॉफ़्टवेयर की वैधता और लाइसेंस स्थिति देखने के लिए **F1** लाइसेंस शॉर्टकट।
